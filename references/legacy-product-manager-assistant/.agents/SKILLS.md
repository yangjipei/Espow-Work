# Skills Index

- `requirement-intake`：需求 / 问题接入
- `current-state-analysis`：现状调查
- `requirement-analysis`：需求分析 + 场景分析
- `impact-analysis`：历史与影响分析
- `goal-definition`：目标与成功标准
- `solution-design`：产品方案设计
- `business-flow-design`：业务规则与流程设计
- `interaction-design`：页面与交互设计
- `product-contract-design`：数据 / 状态 / 权限 / 异常设计
- `product-spec`：方案产品化 / PRD
- `requirement-review`：需求评审
- `change-clarification`：开发答疑 / 需求变更
- `validation-evaluation`：验收 / 上线 / 效果评估

Skills 是独立专业能力，不代表固定执行顺序。
