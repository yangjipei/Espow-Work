# 7. 异常场景

| 异常场景 | 判断条件 | 系统处理 | 后续影响 |
| --- | --- | --- | --- |
| Decision Plan 不可解析 | 催收系统无法完成计划校验 | 当日不投递自动任务，并写入催收系统异常记录表 <!-- REF:LEGACY_BF018 --><!-- REF:D008 --> | 当日计划停止；App 不展示异常 |
| 轮次重复触发 | 同一幂等键已有成功投递记录 | 拦截服务商调用并记录重复触发 <!-- REF:LEGACY_BF030 --><!-- REF:LEGACY_BF031 --> | 不影响既有投递 |
| 服务商受理失败或调用异常 | 投递调用未成功受理 | 当前轮次记为投递失败，不即时重算计划 <!-- REF:LEGACY_BF034 --> | 后续轮次仍按计划判断 |
| 上一轮处理超时 | 下一轮到时，上一轮仍处理中 | 上一轮记为超时失败，继续当前轮次判断 <!-- REF:LEGACY_BF024 --> | 不阻塞后续轮次 |
| 孤立回调 | dispatch_id 无法定位原轮次 | 记录孤立回调，不改变任何轮次 <!-- REF:LEGACY_BF038 --> | 不影响当前计划 |
| 迟到回调 | 原轮次已超时失败或日切终止 | 更新原轮次最新结果并保留迟到标识，不回滚调度终态 <!-- REF:LEGACY_BF040 --> | 不影响当前及后续轮次 |
| WAT 日切 | 当前已不属于原业务日 | 终止当日剩余轮次 <!-- REF:LEGACY_BF022 --><!-- REF:D005 --> | 不跨日续跑 |
| 轮次条件不满足 | 本轮准入条件返回不满足 | 标记为跳过并记录判断结果和原因 <!-- REF:LEGACY_BF027 --> | 等待下一轮 |
| 案件退出 | 轮次投递前命中退出条件 | 记录退出原因并结束当日剩余轮次 <!-- REF:D007 --> | 不再投递剩余轮次 |

# 8. 数据指标

| 指标 | 口径 |
| --- | --- |
| 当日计划数 | WAT 业务日内保存成功的案件级 Decision Plan 数 |
| 计划解析失败数 / 率 | 计划不可解析案件数及其占计划请求数比例 |
| 分轮准入数 / 率 | 各轮满足准入条件的轮次数及其占到时轮次数比例 |
| 分轮投递成功数 / 率 | 服务商成功受理数及其占有效投递数比例 |
| 重复触发拦截数 | 被幂等规则拦截的重复触发次数 |
| 投递失败数 / 率 | 受理失败或调用异常轮次数及比例 |
| 超时失败数 / 率 | 下一轮到时仍处理中的前序轮次数及比例 |
| 迟到回调数 | 原轮次超时失败或日切终止后收到的回调数 |
| 孤立回调数 | 无法通过 dispatch_id 定位原轮次的回调数 |
| 案件退出数 | 命中退出规则并终止剩余轮次的案件数 |
| 异常记录数 | 催收系统异常记录表按异常类型统计的记录数 |

# 9. 验收标准

1. 命中准入的案件，每个 WAT 业务日只保存一份包含 1～3 轮的 Decision Plan；未命中时不创建自动轮次。 <!-- REF:LEGACY_BF014 --><!-- REF:LEGACY_BF015 --><!-- REF:LEGACY_BF016 --><!-- REF:D001 -->
2. Decision Plan 不可解析时，当日不发生自动任务投递，异常写入催收系统异常记录表且可追溯。 <!-- REF:LEGACY_BF018 --><!-- REF:D008 -->
3. 每轮到时读取案件最新状态和历史轮次结果，并按已保存计划执行准入条件。 <!-- REF:LEGACY_BF021 --><!-- REF:LEGACY_BF025 --><!-- REF:LEGACY_BF026 -->
4. 下一轮到时若上一轮仍处理中，上一轮标记为超时失败，当前轮继续判断。 <!-- REF:LEGACY_BF024 --><!-- REF:D002 -->
5. 同一 case_id + business_date + round_no 多次触发时，服务商最多收到一次成功投递。 <!-- REF:LEGACY_BF030 --><!-- REF:LEGACY_BF031 -->
6. 本轮准入后按 tool_code 路由至 IVR 或 AI Robot，并生成唯一 dispatch_id。 <!-- REF:LEGACY_BF028 --><!-- REF:LEGACY_BF032 -->
7. 服务商受理失败或调用异常不阻塞后续轮次。 <!-- REF:LEGACY_BF034 -->
8. 正常回调定位原轮次、更新状态和最新结果，并保留回调轨迹。 <!-- REF:LEGACY_BF036 --><!-- REF:LEGACY_BF037 --><!-- REF:LEGACY_BF039 -->
9. 孤立回调只记录异常，不改变任何计划或轮次。 <!-- REF:LEGACY_BF038 -->
10. 迟到回调只更新原轮次最新结果，不回滚调度终态，不影响当前或后续轮次。 <!-- REF:LEGACY_BF040 --><!-- REF:D003 -->
11. WAT 日切后当日剩余轮次全部终止，不跨日续跑。 <!-- REF:LEGACY_BF022 --><!-- REF:D005 -->
12. 案件投递前命中退出条件时，退出原因可追溯，且剩余轮次不再投递。 <!-- REF:D007 -->
13. Web 端章节完整描述计划解析、轮次执行、工具推送、结果覆盖、异常和案件退出，不出现新增 Web 操作页面。 <!-- REF:D007 -->
14. App 案件列表仅展示当前案件有无其他工具正在作业，不展示具体工具、轮次、执行结果或异常信息。 <!-- REF:PF001 --><!-- REF:PF002 --><!-- REF:D008 --><!-- REF:D009 -->
15. App 不提供暂停、跳过、补投或计划启停入口，坐席可继续人工处理。 <!-- REF:PF003 --><!-- REF:PF004 --><!-- REF:PROTO002 -->

# 10. 风险与影响范围

| 风险 / 影响 | 说明 | 应对 |
| --- | --- | --- |
| Decision Plan 协议不完整 | 缺少时间、工具或条件会导致计划不可执行 | 上线前确认协议 Schema 和必填校验 |
| 服务商状态映射不一致 | 服务商状态与催收系统结果口径不一致 | 建立统一映射表并覆盖正常、失败、迟到场景 |
| 并发触发导致重复触达 | 调度重试或消息重投并发命中同一轮次 | 使用轮次级幂等键并保留重复触发记录 |
| 日切与时区误差 | 非 WAT 口径可能导致跨日或提前终止 | 计划归属、触发和日切统一采用 WAT |
| 作业提示口径不一致 | “有无其他工具正在作业”的判断口径不一致会导致提示错误 | 联调前统一“作业中”的状态范围 |
| 退出条件未完整定义 | 状态枚举不完整可能导致错误触达 | 联调前冻结退出条件与案件状态映射 |

影响系统包括决策引擎、催收系统调度与回调链路、IVR / AI Robot 服务商接口，以及现有 App 案件列表。
