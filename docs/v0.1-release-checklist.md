## Known Limitations

- DeepSeek `deepseek-v4-flash` 的真实 Harness 多轮验收延迟较高，单次完整脚本尚未稳定结束；当前只确认真实 Artifact 读取与 Delta/Approval/Write/Validate 子链路。
- 现有 acceptance 脚本仍包含对模型 Tool 选择的确定性断言，模型采用等价路径时可能导致测试失败；失败输出已改为保留堆栈，后续需按业务结果而非固定 Tool 顺序收口。
- HTML Prototype 已有结构、脚本与交互 Validator，但复杂浏览器视觉回归和跨页面自动操作尚未覆盖。
- 旧 Workspace 的非版本化 Legacy Artifact 可继续浏览，但不会仅凭 `state.yaml.lifecycle_stage` 推进新的派生 Stage。

## V0.1 Status

当前状态：`BLOCKED`。

P0/P1 产品闭环代码、确定性状态模型、Workbench 与构建均已通过；在一个真实 Requirement 完成 `Analysis → Flow → Solution → Interaction → Prototype → PRD → Review → READY` 的同链路验收前，不应标记 V0.1 封版。
